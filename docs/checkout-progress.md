# Покупательский сценарий TIHO

Статусы: не начато / в работе / проверено / заблокировано. «Проверено» означает
фактически выполненную проверку, а не наличие кода. Обновлено: 2026-10-07.

| Обязательное требование | Статус | Свидетельство / следующая проверка |
| --- | --- | --- |
| Изучить TIHO, Planner, Social Analytics и контракты SDK | проверено | Hono/D1, Next/FSD, stateless MCP Apps; исходники референсов и официальные контракты |
| Сохраняемая серверная корзина, количества, точные суммы | проверено | D1, целые минимальные денежные единицы; commerce.spec.ts и браузер сайта |
| Идемпотентность добавления, создания заказа и оплаты | проверено | Разные намерения, повторы, конкурентные операции в тестах D1 |
| Изоляция гостевых сессий и проверка владельца | проверено | HTTP/MCP tests: чужие ID, проверенная identity, hash сессии |
| Подтверждённая привязка сайта и MCP | проверено | Настоящий ChatGPT → одноразовый переход → защищённый preview → тот же заказ после reload; изменения сайта прочитаны из чата |
| Контакты, актуальная сводка, явное подтверждение | проверено | Версия корзины + quote; поля, возврат и reload в браузере |
| Транзакционное сохранение заказа и снимков каталога | проверено | D1 batch, уникальная версия корзины, неизменяемые снимки; интеграционные тесты |
| Сохранение параллельно добавленных товаров, rollback | проверено | Гонки и искусственный отказ записи через DB trigger в тестах |
| Внутренний адаптер: ожидание, обработка, успех, ошибка, повтор | проверено | D1 tests + браузер fail_once: отказ, reload, повтор в том же заказе, успех |
| Отличие внутреннего результата от настоящего платежа | проверено | payment_mode=internal_presentation, result=internal_succeeded; настоящих провайдеров нет |
| Полный интерфейс сайта и сохранённая страница заказа | проверено | scripts/verify-checkout-browser.mjs: 5 групп, мобильный экран и reload |
| Полный интерфейс MCP Apps и текстовые инструменты | проверено | 5 групп локального браузера; полный путь в настоящем ChatGPT, сохранённый заказ и переход на сайт; текстовый get_cart без новой панели |
| Актуальные подключённые инструкции и skill | проверено | Приватный Sites обновлён, инструменты обновлены через настройки ChatGPT, реальная корзина работает |
| Загрузки, ошибки, восстановление, accessibility, мобильный UI | проверено | Mobile, inline validation, back, reload при обработке, fail/retry; потеря ответов create/payment после реального commit без дублей |
| Каталог, сравнение, контекст подборок и раздел «Плагины» | проверено | 8 browser regression групп, sidebar/mobile, сравнение, история, fault/retry |
| Миграции, конфигурация, документация запуска | проверено | 0001 применена к local и remote D1 без удаления каталога; env examples, режимы и запуск описаны в checkout.md |
| Автоматические проверки бизнеса, гонок, доступа и отказов | проверено | Полный pnpm check + целевые проверки окончательных изменений: 41 backend + 27 frontend + 3 MCP unit; contracts/architecture/build проходят |
| Браузер: полный путь сайта и UI плагина | проверено | Локальные browser suites и настоящий ChatGPT/защищённый Vercel preview с remote D1; подробности в checkout-verification.md |
| Целевое разрешённое окружение | проверено | Существующий owner-private Sites, защищённый Vercel preview, API env presentation; публичный production-каталог не менялся |
| Настоящий ChatGPT: полный путь и связь ручных действий с чатом | проверено | Поиск, add 2→3, ручной +→4/6400 ₽, set/add/remove, сводка, заказ TH-261007-302CE79A, оплата, открытие заказа после reload и переход на сайт. Обратная синхронизация: сайт → чат, 3 свечи / 4800 ₽ |

Подтверждённых внешних блокеров нет. Ограничение ChatGPT Unusual activity было
снято владельцем; после этого сценарий завершён. Банк и реальные списания не
подключены по условиям задачи. Границы и свидетельства проверок:
[checkout-verification.md](checkout-verification.md).
