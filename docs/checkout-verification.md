# Проверка покупательского сценария — 2026-10-07

Реализация проверена на трёх уровнях: тестовая D1, локальный браузер с настоящим
API и размещённое окружение с настоящим ChatGPT. Локальный MCP host не считается
ChatGPT. Внешних блокеров после завершения нет.

## Автоматические проверки

`pnpm check` прошёл целиком. После окончательных изменений отдельно прошли
затронутые проверки, сборки и браузерные сценарии. Итог: 41 backend/D1,
27 frontend и 3 MCP unit-теста. OpenAPI, типизация, lint/format, границы модулей,
Next/Vite сборки и Wrangler dry-run проходят.

## Настоящий ChatGPT и размещённый магазин

Использован ранее подключённый приватный TIHO. Инструменты обновлены штатным
действием в настройках ChatGPT. Права доступа и аудитория не расширялись.

1. Поиск свечей до 3000 RUB в наличии, сортировка по цене, три результата на
   странице. «Добавь второй вариант, две штуки» выбрал «Лаванду» из этой подборки.
2. Отдельная команда увеличила количество 2 → 3. Ручной `+` в настоящем iframe
   дал 4; текстовый tool подтвердил 6400 RUB. Затем проверены set/add/remove.
3. Подготовлены фиктивные контакты и актуальная сводка 2 × 1600 = 3200 RUB.
   После явного подтверждения создан заказ **TH-261007-302CE79A**. Оплата запущена
   отдельной командой; повторная проверка не создала второй попытки.
4. После перезагрузки разговора открыта настоящая панель сохранённого заказа.
   «Продолжить на сайте» и стандартный диалог внешней ссылки ChatGPT открыли
   этот же заказ в защищённом Vercel preview. Fragment удалён, cookie недоступна
   JavaScript; reload сохранил доступ к заказу.
5. На сайте пройдены поиск, отдельное повторное добавление, изменение количества,
   добавление второй позиции и удаление. После reload осталось 3 свечи на 4800 RUB.
   ChatGPT прочитал именно эти данные инструментом и ответил текстом без новой панели.
6. На сайте пройдены валидация контактов, сводка, возврат и reload формы, явное
   оформление с двойным нажатием, обработка и завершение оплаты. Сохранённый заказ
   **TH-261007-39F8A286** открылся после полной перезагрузки.

В обычном Chrome проверочная вкладка периодически становилась фоновой.
Восстановление сохранённого заказа дополнительно проверено в активированной
вкладке: скрытые вкладки намеренно приостанавливают polling. Перезагрузка именно
во время обработки и искусственная потеря ответа отдельно проверены локальными
браузерными сценариями, а не заявлены как отдельный облачный тест.

Remote D1 подтверждает для каждого из двух заказов ровно одну попытку со значением
`internal_succeeded` и `payment_mode=internal_presentation`. Суммы — 320000 и
480000 минимальных единиц RUB. На прямой вопрос ChatGPT ответил, что внешний
банковский сервис не подключён и реальных списаний нет. Реквизиты карт, провайдер,
уведомления, доставка и складские операции не вызывались.
