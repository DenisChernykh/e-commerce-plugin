# TIHO — магазин товаров для дома

Fullstack-проект интернет-магазина с каталогом, корзиной, заказами и интерфейсом покупательских действий в ChatGPT через MCP Apps.

## Возможности

- Каталог, поиск, сортировка и фильтры, карточки товаров и категории.
- Серверная корзина, оформление и хранение заказов.
- Общий backend для веб-витрины и MCP Apps; типизированный клиент из OpenAPI.

## Инженерные акценты

- Сквозная реализация e-commerce-сценария от интерфейса до базы данных.
- Идемпотентные операции и обработка конкурентных изменений корзины.
- Повторное использование бизнес-логики между сайтом и AI-интерфейсом.

## Стек

React, Next.js, TypeScript, TanStack Query, Tailwind CSS, Vite, Vitest, Hono, Drizzle.

## Разработка

Инструменты: Node.js 24, pnpm@11.15.1.

```sh
pnpm install
pnpm dev
pnpm check
pnpm test
pnpm build
pnpm lint
```

Параметры окружения перечислены в [frontend/.env.example](frontend/.env.example). Локальные значения задаются вне Git.
