# TIHO — магазин товаров для дома

Интернет-магазин с веб-витриной и покупательским интерфейсом в ChatGPT через MCP Apps. Оба канала используют общие правила каталога, корзины и оформления заказа.

## Возможности

- Каталог, поиск, сортировка, фильтры и карточки товаров.
- Серверная корзина и оформление заказа с хранением данных в D1.
- Защита операций от повторного выполнения и обработка конкурентных изменений корзины.
- Интерфейс магазина и инструменты покупательских действий в ChatGPT.
- Типизированный frontend-клиент, генерируемый из OpenAPI.

## Что показывает проект

Сквозную разработку e-commerce: React/Next.js-интерфейс, Hono API, модель данных Drizzle и оформление заказа. Общая бизнес-логика обслуживает сайт и AI-интерфейс, поэтому правила корзины и заказа не дублируются между каналами. Идемпотентность и контроль версий корзины показывают работу с повторными запросами и конкуренцией — важными задачами коммерческих сервисов.

## Разработка

Node.js 24, pnpm@11.15.1. Настройки: [frontend](frontend/.env.example), [backend](backend/.dev.vars.example), [ChatGPT](chatgpt/.env.example).

```sh
pnpm install
pnpm dev
```

Проверки типов, архитектуры, API-контракта и тестов:

```sh
pnpm check
pnpm build
```

Для локальной базы предусмотрены `pnpm db:migrate:local` и `pnpm db:seed:local`.
